# Unity素材ルール

元のルールはWeb版 `assets/AGENTS.md`。Unity版でも次を守る。

- 基準は初期ハロウィン装備のパンプキンブレード、魔女のマント、月のお守り。移植先の `Assets/LegendHeroes/Resources/LegendHeroes/Art/assets/halloween/` にある原画を参照する。
- 装備とフレームは128×128の論理ピクセル密度、24〜32色、1ピクセルの暗い輪郭、素材ごとに3〜4段階の陰影。高精細の描き込みやぼかしで置き換えない。48px・88pxでも比較する。
- 装備は透過PNG。単刃の武器は刃先が右上、柄が左下。装備の種類ごとにシルエットを分ける。
- フレームは正方形、細い線と四隅の飾り。中央56%と顔の領域（横22〜78%、縦15〜60%）は完全に透明にする。額の前へ月やリボンを垂らさない。キャラを小さくしてフレームに合わせない。
- 拠点・セーブ・戦闘・ランキング・外見プレビューは同じ正方形で、背景cover→キャラcontain・下中央・4%余白→フレームを前面の順に描く。
- 商品一覧と拡大は商品のみ。装備中の背景やキャラと合成しない。
- ID・能力・コストは画像の変更に伴って変えない。新規画像はビットマップで個別生成し、使用したプロンプトと参照素材を記録する。
- Unityの装備とフレームはPointフィルタ、ミップマップなし、Clamp、アルファ有効。インポート設定は元のピクセル密度を作り直す代わりにはならない。
