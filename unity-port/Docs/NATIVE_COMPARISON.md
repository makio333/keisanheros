## 差分・未確認の範囲

- Unityの画面・演出はネイティブUIとして再構成している。WebのCSS、Canvasの全エフェクト、会話の演出を画素単位では再現していない。
- 本番ランキング・本番プレイヤーのセーブを使った書込み試験はしていない。QAパスとテストデータでは本番書込みを防ぐ。
- Webの管理者設定はブラウザ保存、Unityの管理者設定は独立ファイル。ブラウザ内の個別設定を自動で吸い出す処理はない。未知の装備ID・独自データはJSONへ保持するが、定義が存在しない独自装備の表示・装備はできない。
- Mac独立アプリは起動とタイトル描画を確認。CUAのポインター操作は対象ウィンドウ取得が不安定で、開始以降の手動操作は未確認。ゲーム内操作は実Unityシーンの56操作で検証。URPテンプレート由来の未使用ポストエフェクトにシェーダー除外の警告が出るが、ゲーム用UIと画像の表示は確認済み。
- Android/iPhone/iPad実機、縦画面・safe area、OS別の印刷/共有、ストア署名・購入/購入復元・月額課金は未検証/販売準備の範囲。今回のmacOS移植完了と、スマホ販売可能な状態を同一視しない。

## 元データの修正方針

- Web側のarea7・area11に存在しない `bandit_19` 参照がある。書出しは警告して除外し、Webは変更していない。
- Webの平均問題は独立した増減から誤った正解を作る場合がある。Unityの生成は対称な増減で正しい平均にした。
- 比を簡単にする問題はUnityで最大公約数による最小の比を生成する。
- 問題バンク抽出は固定乱数で再現可能。通常の算数出題はC#生成を使い、有限サンプルだけで無限生成を代用していない。
