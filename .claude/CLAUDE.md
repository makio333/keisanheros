# けいさんRPG（タイピングゲーム汎用から計算版に移行）

## プロジェクト概要
- 素早さバー（ATB）方式の**計算専用**バトルRPG（タイピング要素なし）。純粋なHTML/CSS/JS（ビルドなし）
- 構成: `index.html` / `style.css` / `game.js`
- セーブ: localStorage（キー `typing_rpg_save_v3`。旧 `typing_rpg_save_v2` から自動移行あり）
- 起動: `python3 -m http.server` で配信（親フォルダの `.claude/launch.json` に `type-math-rpg-server` 設定あり、ポート8745）

## ゲームフロー（テンポ重視）
- 拠点 → 塔/ダンジョンに入ると**即バトル**
- 敵を倒す → 勝利画面 → 「➡次の階へ進む」で**即次のバトル**（または拠点に戻る）
- 塔は10階・ダンジョンは地下10階。5階と10階がボス。10階制覇で救助イベント＋SSR報酬

## 主要システム
- 入力は半角強制（全角数字は `toHalfWidth()` で自動変換）
- 戦闘: 素早さバーが端に達した方が行動。コマンドは 戦う／スキル／アイテム
- 「戦う」は即けいさんチャレンジ（サブメニューなし）。階が深いほど難しい演算（`opTierForFloor()`）
- 難易度は学校のカリキュラム順に進行: たしざん(1-2階)→くりあがりのたしざん(3-4階)→ひきざん・くりさがり(5-6階、5階ボス)→かけざん(7-8階)→わりざん(9-10階、10階ボス)。`OP_TIERS` / `generateProblem()` 参照
- 残り時間が多いほどダメージボーナス（最大+50%）
- 装備: 装備ごとに割り当てられた演算種別（`opTier`）のけいさんに正解すると装備できる（固定ステータス）
- スキル修行: 演算種別（`tier`）のけいさんに規定回数正解するとマスター（`skillTier()`）
- **戦闘でのスキル発動は「そのステージの問題」**（`currentAttackProblem()`）。スキル固有tierの問題は出さない
  → 理由: スキルを使えばステージの難易度を回避できてしまうため。代わりに強いスキルほどボーナス時間が短い（`skillTimeMult()`）
- 合成: 同レアリティの素材2つを消費し、けいさん2問に連続正解するとレアリティアップ
- レベルアップで+3ポイント、HP/MP/攻撃/防御/素早さに自由に割り振り

## ゲーム詳細ドキュメント（必須更新ルール）
- ファイル: `GAME_DETAILS.md`（プロジェクトルート）
- 毎回アップデートごとに以下を実施：
  1. 新機能・変更・バグ修正をテンプレート形式で記載
  2. 「現在のゲーム仕様」セクションも実装内容に合わせて更新
  3. コードの変更 = `GAME_DETAILS.md` の更新、セットで実施
- 目的：ゲームの完成状態と全変更履歴を記録・共有

## クレジット節約ルール（必須読み込み・遵守）
- ファイル: `クレジット節約.md`（プロジェクトルート）
- **作業開始時および更新時は必ず `クレジット節約.md` を読み込み、トークン消費を最小化すること**
- 巨大ファイルの全件読み込み禁止（`grep` + 行指定 `StartLine/EndLine` の徹底）
- 巨大ファイルの上書き禁止（`replace_file_content` による差分置換）
- ログ・シミュレーション出力の集約（要約された数値のみ出力）
