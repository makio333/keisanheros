# バトル画面テンプレート（もんだい × 入力 × 敵）

> 「けいさんRPG」で つかっている **バトル画面の わりつけ** を、
> ほかのゲームでも つかいまわせるように まとめた テンプレート。
>
> ねらい：**あたらしい 教科（理科・社会・英語…）を ふやす ときは、
> もんだいの ウィンドウの なかみを 入れかえるだけ** で すむようにする。
> 画面の わりつけ・入力キーボード・敵の いちは いっさい さわらない。

---

## 1. 画面の やくわり（4つの まど）

バトル画面は つぎの 4つに わかれる。**やくわりが 1つの まどに 1つ**なのが きほん。

| # | やくわり | いち | ID / class | なかみを 教科ごとに かえる？ |
|---|---------|------|-----------|--------------------------|
| ① | 敵・せんとうフィールド | 画面の うえ（まんなか） | `.battle-field` / `.enemy-sprite` | ❌ かえない |
| ② | ATBゲージ（すばやさくらべ） | 敵の した | `.battle-atb-compare` | ❌ かえない |
| ③ | **もんだいの まど**（＋こたえを うつ らん） | **ATBゲージの すぐ した（ページの ながれの まま）** | `#calc-problem-center`／`#kanji-problem-center` | ✅ **ここだけ 入れかえる** |
| ④ | **キーボードの まど**（テンキー／五十音） | **画面の みぎ**（せまい画面では した） | `#battle-challenge`／`#kanji-challenge` | ✅ 教科の 入力ほうしきに あわせて えらぶ |

**にゅうりょくらんは ③の なか**（もんだいの すぐ した）に おく。
④は「キーを おす ばしょ」だけ。おした もじは ③の らんに 入る。
こうすると 「といを 見る → こたえを うつ」が おなじ ばしょで つながり、
キーボードを けした とき（フリック／物理キーボード）でも
④を まるごと しまうだけで すむ。

そのほか（ぜんぶ かたほうに よせて、①〜④に かぶらせない）：

- ひだり上：かい／ステージ表示（`.floor-window`）
- ひだり：ステータスまど（HP／MP／けいけんち）
- みぎ上：とけい（`#analog-clock-widget`）
- ひだり下 or みぎ：とくぎ／どうぐ（`.battle-side-commands`）
- 右下：うかんでいる ☰／🔊（**入力の まどが ひらいている あいだは しまう**）

### だいじな きまり

1. **もんだいも にゅうりょくらんも かならず ATBゲージの した。** 画面の まんなかや うえに おかない。
   子どもの めせんが 「敵 → ゲージ → もんだい → こたえを うつ」と たてに ながれる。
2. **入力は みぎ（or した）に わける。** もんだいと 入力を 1つの まどに まとめると
   まどが たてに ながくなり、ATBゲージや 敵の なまえに かぶる（じっさいに おきた バグ）。
3. **もんだいの まどは 入力の まどの はばぶん ひだりに よける。**
   `--kanji-gutter` という CSS へんすうで、ATBゲージと もんだいの まどを おなじだけ よける。
4. **修練場・そうび・合成など バトル以外の 画面では 1つの まどに まとめる。**
   わけるのは バトル画面（`container.id === 'battle-challenge'`）の ときだけ。

## 3. CSS（そのまま つかえる ひな型）

```css
/* 入力の まどが ひらいている あいだ だけ、そのはばを よける */
#screen-battle { --kanji-gutter: auto; }
#screen-battle.kanji-battle            { --kanji-gutter: calc(min(320px, 30vw) + 24px); }
#screen-battle:has(#battle-challenge:not(.hidden)) { --kanji-gutter: calc(min(340px, 32vw) + 24px); }

/* ② ATBゲージ と ③ もんだいの まど は おなじだけ よける＝たてに そろう */
#screen-battle .battle-atb-compare,
#screen-battle .problem-window {
  margin-left: auto;
  margin-right: var(--kanji-gutter);
}

/* ③ もんだいの まど：ながれの まま。position は つけない */
.problem-window {

}

/* ④ 入力の まど：みぎに かためる（とけいの した） */

  position: fixed;
  top: 128px; right: 12px; left: auto; bottom: auto;

  margin: 0;

/* スマホ・たて：入力は した いっぱい。敵の エリアを ちぢめて もんだいの ばしょを つくる */

  #screen-battle .input-window:not(.hidden) {
    top: auto; left: 8px; right: 8px; bottom: 8px; width: auto;
    height: min(46vh, 400px);   /* ← ★ 中に flex の こが ある ときは 高さを はっきり きめる */

  body:has(.input-window:not(.hidden)) .mute-button { display: none; }
}

/* スマホ・よこ：はばは あるので みぎに もどす（とけいの ひだり） */
@media (max-width: 820px) and (max-height: 520px) {
  #screen-battle .input-window:not(.hidden) {
    top: 6px; right: 104px; left: auto; bottom: auto;
    width: min(300px, 34vw); height: min(88vh, 340px);
  }
  #screen-battle { --kanji-gutter: calc(min(300px, 34vw) + 116px); }
  #screen-battle .problem-window { width: auto; margin: 8px var(--kanji-gutter) 0 146px; }
  #screen-battle .battle-field   { height: 26vh; }

```

### ハマりやすい ところ（じっさいに ふんだ ぶんだけ）

- **`max-height` だけでは flex の こは 高さを 分けあえない。** キーボードの グリッドが
  0に つぶれて 画面の そとに はみ出す。`height:` を はっきり きめる。
- **`top:auto` ＋ `bottom:auto` に なると `position:fixed` は「もとの ながれの いち」に もどる。**
  メディアクエリを かさねる ときは、かならず どちらかを きめなおす。
- **UIの ぶひんを ふやしたら、下端固定・高さ中身まかせの まどは 上に のびて 上の 要素を かくす。**
  まどを ふやしたら 3サイズ（PC／スマホたて／スマホよこ）で かさなりを かならず みる。

## 4. データの けいやく（ここだけ 教科ごとに つくる）

### ステージ 1つ

```js
{
  name: '10までの たしざん',      // ステージ名（プリントの タイトルにも つかう）
  type: 'kanji' | undefined,     // 入力ほうしきの えらび分け。なければ すうじ入力
  tier: 'kanji_g1_1',            // もんだいの しゅるい（プリント・修行・そうび と きょうよう）
  timeLimit: 5000,               // ミリびょう
  generateProblem: () => ({ … }) // ↓の もんだい を かえす
}
```

### もんだい 1つ

```js
{
  text:   '4 + 2',    // ③の まどに そのまま だす（HTML可）
  answer: 6,          // こたえ（すうじ／文字れつ どちらでも）
  tier:   'add1',     // 任意
  isWordProblem: false // true なら 「= 」ではなく 「こたえ→」で だす（文章題）
}
```

**この 2つさえ かえせば、画面・入力・バトル・プリントは そのまま うごく。**

### もんだいを だす いりぐちは 1つだけ にする

バトル中に もんだいを だす ばしょは `currentAttackProblem()` **だけ**。
「たたかう」も「スキル」も、ぜんぶ ここを とおす。

```js
function currentAttackProblem(){ …ステージ／ボスフェーズを みて もんだいを かえす… }

doAttack(){  const { problem, timeLimit } = currentAttackProblem(); … }
useSkill(s){ const { problem, timeLimit } = currentAttackProblem(); … }
```

**やっては いけない**：スキルや とくしゅコマンドが 自分だけの もんだいを つくること。
かつて スキルが スキル固有の tier で 出題して いたため、
**6年の漢字ステージでも スキルを おせば 1年の たしざんが 出て、
ステージの むずかしさを まるごと 回避できて しまった**。

つよさの さは「もんだいを やさしく する」ではなく、
**MPしょうひ／しゅぎょうの かいすう／ボーナス時間（`skillTimeMult()`）** で つける。

## 5. あたらしい 教科（例：理科）を ふやす てじゅん

1. `理科_data.js` を つくる。
   `SCIENCE_POOLS = { science_g3_1: [ {text:'…', answer:'…'}, … ] }` と
   `generateScienceProblem(tier)` を おく（`kanji_data.js` と おなじ かたち）。
2. `AREA_STAGES` に エリアを 1つ たす。ステージの `generateProblem` から
   `generateScienceProblem('science_g3_1')` を よぶだけ。
3. こたえが **すうじ** なら 何も しなくてよい（テンキーが そのまま つかえる）。
   こたえが **ひらがな** なら `type:'kanji'` と おなじ あつかいに して 五十音パネルを つかう。
   → 入力ほうしきは 「すうじ or かな」の 2しゅるいしか ないので、どちらかを えらぶだけ。
4. ステージせんたく画面の カードを 1まい たす（`showStageSelect()`）。
5. **画面の わりつけ・CSSは いっさい さわらない。**

## 6. れんしゅうプリント（かみ）も おなじ けいやくで うごく

- `printStageSheet(areaId, stageIndex, kind)` は `stage.generateProblem()` を 20かい よぶだけ。
  → あたらしい 教科でも そのまま プリントできる。
- `kind` は `'read'`（そのまま とく）と `'write'`（こたえ→もんだい を さかさに して とく）。
  さかさに できる 教科（漢字の かきとりなど）だけ `'write'` を だす。
- プリントの あたまには エリアの ヘッダー画像（`area.bgImage`）を おびで 入れる。
- あんごうの すうじの つくりかた
  - こたえが **すうじ**：こたえの いちばん うしろの すうじ（テンキーで にゅうりょく）
  - こたえが **ひらがな**：こたえの いちばん さいしょの もじ（五十音キーボード）
  - こたえが **漢字**（かきとり）：こたえの いちばん さいしょの もじ
    （そのステージに でてくる 漢字だけの キーボードを その場で つくる）
- あんごうを あてると、そのステージの モンスターを ぜんぶ たおしたのと
  おなじ けいけんち・ゴールド・ドロップアイテムが もらえる（★は ふえない）。
